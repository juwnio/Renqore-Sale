01 What it is

An LLM recruitment engine, built for the UK.

Renqore sources live jobs from Adzuna's UK market and ranks candidates by fit. A UK recruitment agency uploads a batch of CVs and receives a scored, explained, exportable shortlist for every candidate — in minutes, not days.

Flask + MongoDB Ollama LLM scoring Adzuna UK Stripe billing £0/mo to run

02 What's built — and what's not

The truth, in two columns.

A working beta with its rough edges listed plainly beside it. Nothing here is hidden.

Working & built

  • Adzuna UK job sourcing
  • LLM fit scoring (Ollama, 0–100 + reasoning)
  • Batch & candidate management
  • CV upload, PDF/DOCX parsing & storage
  • Email/password + Google sign-in
  • Multi-tenant orgs & roles
  • Email invitations
  • Stripe subscriptions (trial / grace / expiry)
  • Daily quota (100 evaluations / 24h)
  • Excel exports (org / batch / candidate)
  • Dashboard, docs & mobile view
  • Analytics & in-app feedback

Partial, rough or missing

  • City filter is cosmetic (not sent to Adzuna)
  • “Remote” job type is a no-op
  • Batch runs are synchronous (no worker/queue)
  • One-batch-at-a-time enforced in the UI only
  • No password-reset flow
  • API keys stored unencrypted
  • Only the “starter” plan is reachable
  • Only Ollama is wired up
  • No test suite, CI or Docker
  • Some unused dependencies & dead code
